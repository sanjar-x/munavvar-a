## Decisions Made
- Used `_split_sql()` dollar-quote-aware splitter in trigger migration because asyncpg rejects multi-statement prepared statements. The .sql files contain CREATE FUNCTION (with $$ delimiters) followed by DROP/CREATE TRIGGER statements -- these must be split and executed individually.
- Added `from sqlalchemy import MetaData` to autogenerated init migration because SQLAlchemy 2.1 autogenerate emits `metadata=MetaData()` in Enum column definitions but does not auto-import it.
- Used Railway DB for migration rebuild because Docker Desktop daemon was not running. The result is identical -- fresh schema from `alembic upgrade head`.

**1. [Rule 3 - Blocking] Added MetaData import to autogenerated migration**
- **Found during:** Task 2 (alembic upgrade head)
- **Issue:** Autogenerated init migration used `MetaData()` in Enum column definitions but only imported `sa` and `postgresql` -- NameError at runtime

**2. [Rule 3 - Blocking] Dollar-quote-aware SQL splitting for asyncpg**
- **Found during:** Task 2 (alembic upgrade head for trigger migration)
- **Issue:** asyncpg cannot execute multiple SQL statements in a single prepared statement. The .sql files contain CREATE FUNCTION + DROP TRIGGER + CREATE TRIGGER as separate statements.
- **Fix:** Implemented `_split_sql()` function that splits on semicolons outside dollar-quoted blocks, then executes each statement individually
- **Files modified:** alembic/versions/e169f5901a8e_triggers.py
- **Verification:** alembic upgrade head succeeds, all 4 integration tests pass
- **Committed in:** f102494 (Task 2 commit)

**3. [Rule 3 - Blocking] UTF-8 encoding for SQL file reading on Windows**
- **Found during:** Task 2 (alembic upgrade head for trigger migration)
- **Issue:** Windows default encoding (cp1251) failed to decode Russian comments in .sql files
- **Fix:** Added `encoding="utf-8"` parameter to `read_text()` calls
- **Files modified:** alembic/versions/e169f5901a8e_triggers.py
- **Verification:** alembic upgrade head succeeds
- **Committed in:** f102494 (Task 2 commit)
